# Taller IMIS — Sistema de Pedidos

Sistema de gestión de pedidos para Taller IMIS (bordados y confección).

## Stack
- **Frontend:** HTML + React (CDN) — single file `index.html`
- **Base de datos:** Supabase (PostgreSQL)
- **Deploy:** GitHub Pages (automático al hacer push a `main`)

## URL del sistema
https://njar97.github.io/taller-imis-pedidos/
